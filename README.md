# 🏗️ MEP Engineering Automation Suite

> Professional mechanical / electrical / plumbing calculations — made simple, in the browser.

**▶️ [Open the live app](https://darthsandd.github.io/mep-engineering-suite/)**

A single-file engineering calculator suite for building-services work. No install, no account, no backend — open it and calculate.

---

## What it does

- **Live recalculation** — results update as you type, no submit button
- **Professional-grade formulas** for MEP building services
- **Single-line diagram (SLD)** generation with persistence
- Runs **100% in the browser** — your inputs never leave your machine

## Who it's for

MEP engineers, building-services designers, electrical contractors, and students who need fast, trustworthy numbers without firing up heavyweight CAD or spreadsheet templates.

---

## Tech

`HTML` · `CSS` · `JavaScript` — zero dependencies, zero build step.

Everything ships in one `index.html`, which is why it loads instantly and works offline.

---

## Run locally

```bash
git clone https://github.com/DarthSandD/mep-engineering-suite.git
cd mep-engineering-suite
# just open it
start index.html      # Windows
open index.html       # macOS
```

Or serve it:

```bash
python -m http.server 8080
# → http://localhost:8080
```
