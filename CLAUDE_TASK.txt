## 8 Calculation Tools

Each tool has: form inputs → calculate button → results display

1. **Cable Sizing** (IEC 60364 / BS 7671): power, voltage, PF, length, cable type (copper_pvc/copper_xlpe/al_pvc/al_xlpe), installation method, max VD%, ambient temp → size mm², load current, capacity, voltage drop %, pass/fail
2. **Transformer Sizing**: load kW, PF, diversity factor, margin %, voltage ratio → kVA, primary/secondary current
3. **Short Circuit**: transformer kVA, voltage, impedance%, feeder impedance → momentary & sustained fault current kA
4. **Cooling Load**: area, ceiling height, occupants, equipment kW, lighting kW, window area, U-value, ext/int temp → sensible, latent, total kW & tons refrigeration
5. **Pipe Sizing** (Darcy-Weisbach): flow rate, length, max pressure drop, fluid (water/air/oil), fittings → diameter mm, velocity, actual pressure drop
6. **Pump Sizing**: flow rate, total head, density, efficiency% → hydraulic power, shaft power, motor kW (standard sizes)
7. **Beam Deflection**: span, load, load type (point/UDL/fixed), E modulus, section type & dimensions → deflection mm, stress MPa, pass/fail vs L/250
8. **Column Buckling** (Euler/Johnson): length, load, section, end conditions, yield strength → critical load, slenderness ratio, FoS, safe/unsafe

## Calculation Logic (Port from Python — keep formulas exact)

**Cable**: I_load = P/(V*PF*sqrt(3)); derate by installation method + ambient temp; iterate standard sizes; R from table * temp correction; Vd = sqrt(3)*I*R*L

**Transformer**: S = kW/PF; diversified = S/diversity; kVA = div*(1+margin%); pick next standard size

**Short Circuit**: Z_base = V²/S_kVA; Z_total = Z%*Z_base + Z_feeder; Ik = V/(sqrt(3)*Z); momentary = Ik*1.15

**Cooling Load**: envelope = win_area*U*ΔT; occupants 75W sens + 60W lat each; equipment direct; lighting*1.2; total/3.517 = tons

**Pipe**: Iterate D from 50mm up; A=πD²/4; v=Q/A; Re=ρvD/μ; f from laminar(64/Re) or Colebrook; dp = f*(L/D)*(ρv²/2) + ΣK*(ρv²/2); stop when dp < max

**Pump**: P_hyd = ρgQH; P_shaft = P_hyd/η; motor = next standard size above P_shaft*1.1

**Beam**: Point mid: δ = PL³/(48EI); UDL: δ = 5wL⁴/(384EI); Fixed: δ = PL³/(192EI); limit L/250; stress = M*y/I

**Column**: λ = L_eff/r_min; if λ>100: Euler P_cr = π²EI/L²; else Johnson; FoS = P_cr/P_applied; safe if FoS≥1.5
